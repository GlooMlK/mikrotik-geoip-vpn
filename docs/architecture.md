# Архитектура GeoIP VPN на MikroTik

## Обзор

Система обеспечивает автоматическую маршрутизацию трафика на роутере MikroTik:
- **Российские ресурсы** → напрямую (максимальная скорость, RU IP)
- **Иностранные** → через VPN (VLESS + Reality)
- **Локальная сеть** → без изменений

## Компоненты

### MikroTik (роутер)
- **mangle**: одно правило ALL-LAN — весь трафик с bridge → routing-mark to-vless
- **veth**: виртуальный интерфейс MIHOMO (12.0.0.1 ↔ 12.0.0.5)
- **routing table**: to-vless → default via 12.0.0.5

### Mihomo (контейнер)
- **TUN**: перехватывает весь входящий трафик с veth
- **GeoIP/GeoSite**: определяет страну назначения по IP
- **Rule-providers**: скачивает гео-базы каждые 6 часов
- **VLESS+Reality**: туннель к VPN-серверу

### VPN-сервер (VPS за рубежом)
- **Xray**: VLESS + Reality инбаунд
- Принимает соединения от mihomo
- Выпускает трафик в интернет

## Поток трафика

```
[Устройство в LAN]
       |
       v
[MikroTik bridge]
       |
       v (mangle: dst не локалка → mark to-vless)
[routing table to-vless → 12.0.0.5]
       |
       v
[Контейнер mihomo TUN]
       |
       v
[GeoIP правила]:
  ├── не RU IP? → VPN
  ├── RU IP? → DIRECT (обратно через роутер)
  ├── локальный IP? → DIRECT
  └── всё остальное → VPN
       |
       ├── DIRECT → container eth0 → роутер → ISP → RU-сайт
       |
       └── VPN → VLESS+Reality → VPS → интернет → сайт
```

## Безопасность (fail-closed)

| Сценарий | Поведение |
|---|---|
| VPN-сервер недоступен | Иностранные ресурсы недоступны (не уходят в DIRECT) |
| Контейнер mihomo упал | Весь трафик с LAN прекращается (нет fallback) |
| Гео-база не скачался | Используется кэшированная версия |
| Новый иностранный IP | Автоматически через VPN (не RU IP) |
| Приложение с голым IP | GeoIP проверяет по IP |

## Почему GeoIP, а не домены?

| Подход | GeoIP | Домены (fake-ip) |
|---|---|---|
| Ручные списки | НЕ нужны | нужны |
| Приложение без DNS | ловится по IP | пролетает |
| DNS-петли | нет | возможны |
| Обслуживание | нулевое | постоянное |
| Новый иностранный | автоматически VPN | вручную вписать |

## Метрики (реальные замеры)

| Метрика | Значение |
|---|---|
| RU-сайты (DIRECT) | 45-60 мс |
| VPN-ресурсы | 500-900 мс |
| Пропускная способность VPN | 8-14 МБ/с |
| Гео-базаов IP | 75 000+ |
| Обновление | каждые 6 часов |
